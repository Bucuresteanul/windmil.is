- This public repository for project state, method and decision architecture.

## Current evidence position

Primary-source evidence currently establishes that:

- Vaðalda, Iceland's first utility-scale wind farm, entered operation in September 2026.
- Its main turbine package was awarded to Enercon.
- Its principal foundations and civil-works package was awarded to Ístak.
- Construction remains phased through 2027 according to published project schedules.
- Formal procurement and qualification channels are material to market access.

See [Evidence Register](./EVIDENCE-REGISTER.md).

## Current strategic implication

Vaðalda is evidence that the Icelandic utility-scale wind market is real.

It is **not** currently treated as an open primary-package opportunity for windmil.is because the main turbine and civil / foundation scopes identified so far are already contracted.

The next target is therefore the first credible combination of:

**future project + open package + qualification path + acceptable economics**
