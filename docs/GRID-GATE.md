# Grid Gate — Icelandic Wind Market Entry

**Project:** windmil.is  
**Evidence cutoff:** 2026-10-08  
**Purpose:** Determine whether a wind project has a credible transmission path before it is treated as commercially actionable.

This is a public decision-support document. It is not a connection offer, capacity reservation or grid study.

---

## Executive Position

In Iceland, a credible wind project is not defined by wind resource, land and environmental progress alone.

For market-entry purposes:

**project maturity = development maturity + regulatory path + credible grid path + procurement path**

A project whose grid connection is unverified should not be treated as bid-ready, even if its environmental work is advanced.

---

## 1. The Current System Plan Is Approved

The Electricity Regulatory Authority approved Landsnet's **System Plan 2025–2034** on 10 April 2026.

Landsnet describes the plan as the formal framework for transmission-system development over the next decade, with emphasis on:

- reinforcement of the main transmission system
- improved security of supply
- increased transfer capacity between regions
- a three-year execution programme for near-term projects

## 2. Connection Feasibility Is Project-Specific

Landsnet's generator-connection process begins with a preliminary connection inquiry.

The published guidance asks developers to provide, among other items:

- power in MW and utilisation
- project / collection-point location
- single or double connection requirement
- generation technology
- planned energisation date
- ramp-up plan
- status of preparation and permitting

Landsnet then analyses:

- possible connection points
- transmission capacity
- required system reinforcement
- likely connection timing
- estimated connection cost and system contribution

The preliminary result is **non-binding**. More detailed work is required before a project can proceed to formal negotiations.

### Decision consequence

A generic statement such as “the grid is nearby” is not sufficient evidence of connection readiness.

**Primary sources**
- https://www.landsnet.is/page/17e981c5-10b3-42cc-8ed2-91425c8e298c
- https://www.landsnet.is/vidskipti/vidskiptavinir/nyr-vidskiptavinur/fyrirspurn-um-tengingu/

## 3. Garpsdalur — Plausible Connection Concept, Material System Gate

EM Orka currently states that Garpsdalur is approximately **6 km north-east of Landsnet's 132 kV Geiradalur substation**.

Its published concept assumes:

- a 33 kV internal collection system
- step-up to 132 kV onsite
- an underground connection to Geiradalur
- a grid-integration study carried out with Landsnet in 2019

This is meaningful project evidence, but it is not a current connection agreement or capacity reservation.

**Developer source**  
https://www.emorka.is/project

### Regional system constraint

Landsnet's 2026–2028 execution-plan analysis describes low system strength in the affected Westfjords network around:

- Geiradalur
- Glerárskógar
- Mjólká
- Kollafjörður

The same analysis notes the absence of N-1 connection in the relevant baseline and associated voltage-quality constraints.

This analysis appears in the context of Hvalá connection alternatives, not Garpsdalur itself.

### Correct interpretation

**FACT:** the regional transmission system has documented strength / voltage constraints.  
**FACT:** Garpsdalur's developer has studied a Geiradalur connection concept.  
**UNKNOWN:** whether today's system can accept the current Garpsdalur design, on what timetable, at what cost, and under what reinforcement conditions.

Do not convert a 2019 integration study into a 2026 connection commitment.

**Primary source**  
https://www.landsnet.is/library/?itemid=37713e59-8982-4c20-bd85-ae3deb4cfb27

## 4. Westfjords Reinforcement Is Active

Landsnet's 2026–2028 plan includes Westfjords development such as:

- Miðdalur — new 132 kV delivery point
- Kollafjörður — new 132 kV substation
- Miðdalslína 1 — Miðdalur to Kollafjörður
- Hvalárlína 1
- reactive-power equipment at Mjólká

Landsnet states that Miðdalslína 1 strengthens the main Westfjords transmission system.

### Decision consequence

The network is evolving materially.

That makes old connection assumptions unsafe in both directions:

- historical constraints should not automatically be treated as permanent
- planned reinforcement should not automatically be treated as spare capacity for Garpsdalur

A current project-specific Landsnet finding is still required.

## 5. Garpsdalur Has a Published Framework-Era Connection-Cost Estimate

Framework Programme supporting material published a Landsnet-derived connection-cost estimate for Garpsdalur of:

- **ISK 1,076 million**
- **ISK 1,345 million including a 25% uncertainty allowance**

The same material published comparative estimates for other wind concepts.

### Boundary

This is a historical planning estimate, **not a current Landsnet quote**, not a tariff commitment and not evidence that the connection is presently available.

### Why it matters

It provides a useful order-of-magnitude benchmark and a strong reason to model grid connection as a separate capital / project-risk line rather than burying it inside generic development cost.

**Official public source**  
https://samradapi.island.is/api/Documents/89ea7a76-9cb8-ef11-9bc8-005056bcce7e

## 6. Þorlákshöfn — Strong Regional Reinforcement Signal, Project Connection Unknown

Landsnet is developing **Þorlákshafnarlína 2**, an approximately 21 km connection between Hveragerði and Þorlákshöfn.

Landsnet states that substantial development is planned in Þorlákshöfn and that the purpose is to strengthen the existing system to support that development.

The line is planned to be energised in **late 2027**.

### Boundary

This is a regional infrastructure signal.

It is **not** evidence that Þorlákshafnarlína 2 is being built specifically for wpd's Þorlákshafnargarður wind concept, nor that capacity is reserved for that project.

**Primary source**  
https://www.landsnet.is/framkvaemdir/yfirlit-framkvaemda/framkvaemd/hveragerdi-thorlakshofn

## 7. Transmission Construction Is Itself a Material Infrastructure Market

Landsnet announced planned 2026 transmission investment of approximately **ISK 14 billion**, with more than **ISK 7 billion** of works expected to be tendered.

The published split was roughly balanced between:

- earthworks / buildings
- electrical equipment / installation

Landsnet explicitly encouraged contractors and suppliers to monitor its procurement portal.

### Decision consequence

windmil.is should distinguish two adjacent opportunity classes:

**A. wind-farm construction packages**  
**B. transmission / substation civil and installation packages**

They overlap in capability but have different buyers, qualification requirements and commercial logic.

This creates a possible adjacent market-entry route that should be evaluated separately rather than assumed.

**Primary source**  
https://www.landsnet.is/utgafa-og-samskipti/frettir/frett/?documentid=d24bd75a-659e-4a06-a64d-20eca8ca5acc

## 8. System Tightness Does Not Equal Connection Availability

Landsnet's 2025–2029 system-balance report states that, absent action, the probability of energy shortage rises from approximately **14% in 2026** to around **70% in 2029**, while transmission bottlenecks constrain the movement of energy.

### Correct interpretation

This supports the strategic need for new generation and stronger infrastructure.

It does **not** prove that any specific wind project can connect.

**Primary source**  
https://www.landsnet.is/utgafa-og-samskipti/ritogskyrslur/kerfisjofnudur-2025/

# Grid Readiness Model

## G0 — Unknown

No credible project-specific connection path.

## G1 — Concept

Developer has identified a plausible point / configuration, but current system feasibility is not established.

## G2 — Preliminary Landsnet Finding

Current preliminary connection analysis identifies plausible connection conditions, timing and estimated cost.

## G3 — Negotiation / Defined Reinforcement

Formal negotiations or an equivalent documented connection path are underway; material reinforcement and cost responsibilities are bounded.

## G4 — Contracted / Construction-Ready

Connection arrangements, required works, timing and commercial obligations are sufficiently committed for construction planning.

# Decision Rule

Do not move a target into commercial-preparation priority solely because:

- environmental work is advanced
- the site is close to a substation
- the region is receiving transmission investment
- Iceland needs more electricity

For a serious bid horizon, require evidence that the grid path is at least approaching **G2**.
